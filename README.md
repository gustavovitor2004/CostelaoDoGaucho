# 🔥 Costelão do Gaúcho - Churrascaria Tradicional

O site oficial do **Costelão do Gaúcho**, a churrascaria que traz o autêntico sabor dos pampas para Lauro de Freitas, Bahia. 

Este projeto é uma landing page moderna, responsiva e de alta conversão, projetada para destacar o cardápio premium, a estrutura familiar da churrascaria e facilitar reservas diretas via WhatsApp.

---

## ✨ Funcionalidades Principais

- 📱 **Design Totalmente Responsivo:** Experiência fluida e otimizada para smartphones, tablets e computadores.
- ⚡ **Alta Performance:** Construído inteiramente com HTML5 estruturado e CSS3 moderno, sem dependências pesadas, garantindo um carregamento instantâneo.
- 🎯 **SEO Avançado:** Otimizado com tags meta, dados estruturados Open Graph e hierarquia semântica ideal para mecanismos de busca.
- 🥩 **Cardápio Premium Digital:** Seção visual e interativa com os principais cortes de carnes, bebidas e acompanhamentos.
- 💬 **Integração de Contato:** Botão flutuante de WhatsApp configurado com mensagem personalizada de reserva automática e barra de urgência atrativa.
- 🗺️ **Localização Integrada:** Seção com mapa interativo do Google Maps para fácil navegação até o estabelecimento em Buraquinho.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica avançada.
- **CSS3:** Estilização responsiva com variáveis CSS (Custom Properties), transições suaves e animações modernas.
- **Google Fonts:** Tipografia premium combinando as fontes *Oswald* e *Roboto*.

---

## 🚀 Como Visualizar o Projeto

Para rodar e visualizar o site localmente:

1. Clone este repositório:
   ```bash
   git clone https://github.com/gustavovitor2004/CostelaoDoGaucho.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd CostelaoDoGaucho
   ```
3. Abra o arquivo `index.html` em qualquer navegador web de sua preferência (Chrome, Firefox, Edge, Safari).
